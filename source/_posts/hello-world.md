欢迎来到我的博客！这是第一篇文章。

本站使用 **Hexo + Butterfly** 搭建，托管在 **GitHub Pages** 上，零成本。

## 写一篇新文章

```bash
hexo new "文章标题"
```

## 本地预览

```bash
hexo server
```

然后访问 http://localhost:4000/blog/ 。

## 发布

推送到 GitHub 后，Actions 会自动构建并部署。
